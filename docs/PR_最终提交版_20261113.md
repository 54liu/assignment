课堂试用中，全文获取失败后可用篇数不足、时间预算无法自行调整，综合报告还会因输出截断或结构错误无法交付。本 PR 整合全文候选替补、可配置预算和逐环节方法开关，并将综合报告改为“生成结构字段 → 严格校验 → 本地排版”，保留旧版用于对照。

## 主要变更

- **综合报告**：新增独立 `legacy / structured` 开关，默认 `structured`。模型只生成报告所需结构字段，本地组装 Markdown，减少重复输出；格式、schema、引用错误或明确长度截断最多额外生成一次。保留完整输入笔记、严格引用检查和旧版自由报告路径。
- **全文获取与失败替补**：按排名分批尝试后续候选，失败或无可读正文时补位；限制尝试次数与阶段预算，修复来源排队占用单地址下载预算的问题。保留失败与部分正文状态。
- **桌面设置**：提供默认、慢速网络、自定义时间预算；来源、排序、PDF 转换、单篇分析、综合报告分别设置，互斥方案在同一环节选择；长路径省略并支持查看完整路径。保存后作用于新任务，保留已有用户配置和历史。
- **研究对照**：加入 Crossref 元数据、CPU layout 解析，以及可选联合重排、证据检索、全文证据和分段分析。保留基线，单篇分析默认仍为 `direct`；尚未证明优越性的方案作为实验选项。
- **结果可追溯**：修正 arXiv 版本缓存身份与 QASPER 可拒答评分，隔离任务 Markdown/报告，记录输入及配置指纹，补齐依赖模块、测试和正负实验记录。

## 综合报告对照结果

最终修订版使用同一五篇论文的固定笔记，三组配对交替运行；同模型 `deepseek-flash`、相同完整笔记、相同 4000 输出 token 上限。下表仅统计最终修订版，首批六对开发实验另行记录。

| 最终三组配对实验 | 旧版自由报告 | 结构化报告 |
| --- | ---: | ---: |
| 可读且严格校验通过 | 0/3 | 3/3 |
| 报告阶段耗时中位数 | 22.81 秒 | 9.27 秒 |
| 耗时范围 | 21.89–23.17 秒 | 8.85–9.80 秒 |

旧版三次均达到输出上限并被拒收，新版三次均首次生成通过。报告阶段耗时中位数降低约 **59.3%**；旧版计时是失败尝试耗时，新版输出更精简，因此不解释为同篇幅报告或端到端成功交付提速。

首批另有六对报告对照：旧版 0/6、新版 6/6，其中三轮重新分析均得到 5/5 可用笔记；该结果属于提示词最终修订前的版本。所有失败和长尾原始值保留，未事后删除慢样本。一次格式恢复分支有合成错误回归，本批真实实验没有测得其独立挽救率。

## 负结果与边界

- 修复前 33 轮完整消融只有 4/33 份可读报告、0/33 份严格报告；固定文档回放也复现新旧版共有的 4000 token 截断，不能把这部分失败都归为网络。本次修复后未重跑全部端到端消融。
- 下载链路存在显著长尾；增加等待预算不能保证更快或每轮 5 篇。运行方案采用按排名分批替补，滚动替补、渐进短超时和断点续传实验不进入本次运行路径。
- 证据分析仍有 `citation_quote_mismatch` 失败，篇内并发尚未建立稳定优势。人工核查结构化报告仍发现成本口径与无依据否定判断，**不宣称事实准确率不下降或整套系统稳定更快、更准**。
- 联合重排依赖可选语义环境和本地模型权重；缺失时回退基线。当前保留已保存的用户设置，报告默认值变更不会覆盖显式 `legacy` 配置。
